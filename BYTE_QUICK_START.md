## 🎯 How It Works

### 1. Wake Byte
**Say:** "Byte"
**Byte:** "Hello! What can I do for you?"

### 2. Give Command
**Say:** "Open Gmail only"
**Byte:** "Got it! Working on it..."
**Byte:** "Done!"

### 3. Byte Asks Feedback
**Byte:** "Anything else?"

### 4. Continue or Sleep
**Option A - Continue:**
**Say:** "Yes" or give next command
**Byte:** Executes and asks again

**Option B - Sleep:**
**Say:** "Sleep" or "No"
**Byte:** "Going to sleep. Say 'byte' to wake me!"

### 5. Wake from Sleep
**Say:** "Byte"
**Byte:** Wakes up and greets you again

## 🎤 Voice Commands

### Wake Word
- "Byte" ✅
- "Bite" ✅ (alternative)
- "Bait" ✅ (alternative)

### Task Commands
- "Open Gmail only"
- "Search for Python tutorials na"
- "Do one thing, open VSCode"
- "Kindly open LinkedIn"

### Sleep Commands
- "Sleep"
- "So ja" (Hindi)
- "No" (when asked for more tasks)

### Continue Commands
- "Yes" / "Yeah" / "Haan"
- Or just say your next command

## 💡 Pro Tips

1. **Speak Naturally** - Byte understands Indian English
2. **Wake Word Variations** - "Byte", "Bite", "Bait" all work
3. **Direct Commands** - When awake, just say command (no need to repeat "byte")
4. **Quick Sleep** - Say "sleep" anytime
5. **Hindi Words** - "Haan", "Nahi", "So ja" work too
