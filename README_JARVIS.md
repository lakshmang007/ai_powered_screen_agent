# 🤖 JARVIS - Iron Man Edition

This is the enhanced JARVIS version of the AI Screen Agent, featuring a personality inspired by Tony Stark's assistant.

## 🚀 How to Run

```bash
python jarvis.py
```

## 🎤 Voice Commands

### Wake Word
Say **"JARVIS"** to wake him up.

### New Features

1.  **Install Applications**
    - "JARVIS, install Spotify"
    - "Install VSCode"
    - "Can you install Discord?"
    - *Uses Windows Package Manager (winget)*

2.  **Go to Websites**
    - "JARVIS, go to youtube.com"
    - "Go to the website github.com"
    - "Visit google.com"

3.  **Iron Man Personality**
    - Calls you "Lucky" (or you can change this in the code)
    - Responds with "Right away", "At your service", "Systems operational"

### Classic Features
- "Open [App Name]" (Smart opening)
- "Search for [Query]"
- "Type [Text]"
- "Sleep" / "Wake up"

## ⚙️ Requirements
- Windows 10/11
- `winget` (App Installer) for installation features
- Microphone and Speakers
