# Enhanced App Opening and Interruption

## App Opening with Windows Search
You can now explicitly ask JARVIS to open an application using Windows Search (Win+S). This is useful for apps that are not found in standard paths or the Start Menu index.

**Commands:**
- "Open Dolby Access using Windows"
- "Open Spotify in Windows"
- "Launch Notepad via Windows"
- "Search for Calculator with Windows"

JARVIS will:
1. Press `Win+S`.
2. Type the application name.
3. Ask you to confirm if the app is visible in the results.
4. Open it if confirmed.

## Interruption
You can interrupt JARVIS while it is performing long-running tasks, such as the Windows Search sequence.

**How to Interrupt:**
- Click the "Stop" / "Interrupt" button on the JARVIS Overlay.
- Say "Stop", "Cancel", "Wait", or "Don't" during the voice interaction phase of the search.

**Behavior:**
- If interrupted via the Overlay button, JARVIS will immediately stop the current action (e.g., stop typing or waiting) and return to the "Ready" state.
- If interrupted via voice command during a question, JARVIS will acknowledge and cancel the operation.
